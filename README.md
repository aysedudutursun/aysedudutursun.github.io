# Ayşe Dudu Tursun — Portfolyo

https://aysedudutursun.github.io

Bu depo portfolyomun GitHub Pages sürümüdür (ücretsiz, Türkiye dahil her yerden açılır).

| Dosya | Ne işe yarar |
|---|---|
| `index.html` | Sayfa iskeleti |
| `site/icerik.js` | **Bütün yazılar** (5 dil). Düzenlemek için bu dosyayı açın. |
| `site/stil.css`, `site/motor.js` | Tasarım ve sayfayı oluşturan kod |
| `profil.jpg` | Profil fotoğrafı |
| `vaka/` | Okuma Pusulası vaka çalışması sayfası |

Yönetim paneli, iletişim formu ve "Güvenlik Laboratuvarı Bulgularım" (veritabanı) bölümü
yalnızca Next.js sürümünde çalışır: https://github.com/aysedudutursun/portfolyo-2516016019

Yazı değiştirdikten sonra tarayıcı eski hâli gösterirse `index.html` içindeki `?v=4`
sayılarını artırın (ör. `?v=5`).
